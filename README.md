## 🚀 Featured Projects

### 🔹 1️⃣ NexaFlow — RAG-Based Persona-Adaptive Support Agent

<strong>Problem:</strong> Generic customer support bots give the same tone and depth to every user, regardless of context or urgency.

<strong>Approach:</strong>
<ul>
<li>Built a Retrieval-Augmented Generation pipeline with ChromaDB for semantic search</li>
<li>Designed persona-adaptive response logic that adjusts tone and detail to the user</li>
<li>Implemented escalation-sensitivity tuning to flag conversations needing human handoff</li>
<li>Migrated backend across Claude API, Gemini, and finally local Llama 3.2 via Ollama for zero-cost inference</li>
</ul>

<strong>Impact:</strong>
<ul>
<li>Fully self-hosted, no dependency on paid API tiers</li>
<li>More context-aware responses than a static prompt-response bot</li>
<li>Working escalation logic tested against edge-case conversations</li>
</ul>

<strong>Tech Stack:</strong> Python, LangChain, Ollama, ChromaDB, Llama 3.2

<a href="https://github.com/SubhansuPradhan/NexaFlow">🔗 Repo</a>

### 🔹 2️⃣ DataLyst — Interactive Data Analysis & Visualization Platform

<strong>Problem:</strong> Non-technical users need to run EDA, forecasting, and anomaly detection without writing code for every dataset.

<strong>Approach:</strong>
<ul>
<li>Built a Streamlit platform for CSV/Excel upload with automated cleaning and missing-value handling</li>
<li>Implemented model-based feature selection (Linear Regression, Decision Tree, Random Forest) with RFE and human-readable explanations</li>
<li>Added time-series forecasting using Prophet with ARIMA fallback</li>
<li>Built anomaly detection using Isolation Forest and DBSCAN with cluster visualizations</li>
</ul>

<strong>Impact:</strong>
<ul>
<li>One platform covers EDA, feature selection, forecasting, and anomaly detection end to end</li>
<li>Performance safeguards handle large datasets without crashing the app</li>
</ul>

<strong>Tech Stack:</strong> Python, Streamlit, Scikit-learn, Prophet, Statsmodels, Plotly

<a href="https://github.com/SubhansuPradhan/DataLyst-An-Intractive-Data-analysis-Visualization-Platform">🔗 Repo</a>

### 🔹 3️⃣ Retail Store Performance Analytics

<strong>Problem:</strong> Retail businesses need a unified view of store performance, profitability, inventory, and customer trends across regions.

<strong>Approach:</strong>
<ul>
<li>Built an end-to-end pipeline on the Superstore dataset (9,994 transactions, 4 regions, 49 states)</li>
<li>Engineered features including profit margin, fulfillment days, discount tiers, and RFM scores</li>
<li>Designed a star schema in PostgreSQL with SQL queries for store, profitability, inventory, and customer analysis</li>
<li>Built RFM-based customer segmentation (Champions / Loyal / At Risk / Lost)</li>
<li>Connected Power BI directly to PostgreSQL for live dashboards</li>
</ul>

<strong>Impact:</strong>
<ul>
<li>Answers concrete business questions: underperforming segments, margin-eroding discount tiers, loss-making sub-categories, retention by cohort</li>
<li>Reusable pipeline from raw CSV to SQL warehouse to BI dashboard</li>
</ul>

<strong>Tech Stack:</strong> Python, PostgreSQL, SQL, Power BI, Pandas

<a href="https://github.com/SubhansuPradhan/Retail-Store-Performance-Analytics">🔗 Repo</a>
